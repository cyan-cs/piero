# Supporting piero

## Eligibility and contact

Individuals, companies and organizations can support piero's development and maintenance.
For sponsorship inquiries, contact [@dev_cyan on X](https://x.com/dev_cyan).
Amounts, duration and corporate logo arrangements are discussed individually before publication.
Sponsorship does not promise development priority, feature delivery or endorsement.

## Recognition and placement

- [SPONSORS.md](../../SPONSORS.md) holds individual and corporate acknowledgments.
- Individual sponsors receive the same recognition regardless of contribution amount.
- Corporate logos may appear in the sponsor section of the English and Japanese README under agreed terms.
- Publish a name, logo or link only with the sponsor's permission. Private and anonymous sponsors are not identified.
- The application contains no sponsor advertising or corporate-logo list.

## Duration and changes

Review the list monthly. For monthly corporate sponsorship, remove the logo when
sponsorship ends unless a different duration was agreed in advance. With permission,
a former supporter's name may remain in SPONSORS.md as a past supporter.
Requests to change or remove an acknowledgment use the same contact above.

## Funding links

Publish an individual GitHub Sponsors link only after the maintainer confirms that
the receiving profile is active. No confirmed funding link is listed here.
Bug reports, translations, documentation and code contributions are also welcome;
see [contributing](contributing.md).

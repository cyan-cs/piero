# 機能

## 移動と表示

親フォルダー、現在のフォルダー、プレビューを横に並べて表示します。
実行中はフォルダーごとのカーソルとスクロール位置を保持しますが、フィルターは復元しません。
一覧と先読みには[処理量の上限](architecture.md#移動と表示の上限)があります。
リモート・クラウド上のファイルは自動プレビューの対象外です。

ドライブのルート(またはWSLディストリビューションのルート)から親へ戻ると「このPC」が開き、ドライブと登録済みのWSLディストリビューションが並びます。来たほうが選ばれ、Enterで戻れます。一覧の表示のために何も起動せず、ここでは作成・コピー・移動・削除はできません。

英語・日本語のUI、Standard/Nano/Vim/Customキー、8つの組み込みテーマ
(Spade、Heart、Diamond、Club、Joker、King、Queen、Ace)、最大8つのカスタムテーマに対応します。
ファイルマネージャーではマウスのクリック、ダブルクリック、ホイールを使えます。
[キー操作](keybindings.md)と[設定](configuration.md)を参照してください。

タブ(`t`、`w`、`[`、`]`)は最大8個のフォルダーとカーソル位置を実行中だけ保持し、
`--continue`には含めません。場所(`m`のあと文字、`'`のあと文字)は、設定の`[places]`に保存します。
セッションの保存は既定で無効です。`--continue`を使う前に`[session] persist=true`を有効にしてください。

## プレビューとアーカイブ

テキストプレビューは読み取り量を制限し、端末制御文字を無害化します。
Markdownでは見出し、リスト、強調、コード、リンク、表を整形して表示します。
参照形式のリンク先は、展開前の合計で4 MiBまでです。上限を超える参照は記法のまま表示します。
HTMLは文字として表示し、リンク先や画像は取得しません。CSV/TSVは二重引用符で囲むフィールドを扱い、
最大200レコード、64列、各フィールド32セルで桁をそろえて表示します。
RFC 4180の適合検査ではありません。閉じていない引用符は入力の末尾までをフィールドとして表示します。

画像・PDFのプレビューは既定で有効です。PNG/JPEG/GIF/BMP/TIFF/ICOはWICで処理し、
WebP/HEIF/JXLは導入済みのコーデックに依存します。PDFはWindows.Data.Pdfを使います。
デコードは追加の機能権限を与えないAppContainerで、メモリと時間に上限を設けて行います。
失敗してもUIプロセスでデコードしません。Sixelの自動選択には端末の対応機能とピクセル寸法の確認が必要で、
使えない場合は文字セルで表示します。Sixelの明示指定は検出条件の一部を省略します。[設定](configuration.md)を参照してください。これらの検査で、すべての破損ファイルを検出できるわけではありません。

変更せずに閲覧できる形式はZIP/ZIP64、7z/solid 7z、TAR、`.tar.gz`/`.tgz`、
`.tar.xz`/`.txz`、`.tar.zst`/`.tzst`、単一の`.gz`、`.xz`、`.zst`ストリームです。
内容から形式を判定します。パスワード付きや入れ子のアーカイブには対応しません。
リンクは表示するだけで、たどりません。RAR/CAB/ISO/cpio/bzip2/lz4は組み込まれていません。

ZIPは展開もできます。Standardキーでは、アーカイブ内で`y`を押して選択した項目
(なければカーソル下)を取り込み、ローカルフォルダーで`p`を押して展開します。
ほかの形式は閲覧のみです。展開は隠し作業フォルダー`.wfextract-*.dir`で名前とデータを検査し、
コピーエンジンで配置します。既存のフォルダーは統合し、ファイル名の衝突はコピー時の確認に従います。
上限は各ファイル16 GiB、合計64 GiB、200000項目で、作業用とコピー先の両方の空き容量が必要です。
クラッシュすると作業フォルダーが残る場合があります。中止すればすべて消えると考えず、結果と残存ファイルを
確認してください。アーカイブ自体を書き換える操作はありません。

## エディターとGit

エディターはUTF-8、BOM付きUTF-8/UTF-16、設定したコードページに対応します。
判定が不確かな場合は確認と往復変換の一致が必要です。行ごとのLF/CRLF/CR、BOM、最終改行の有無を保持します。
既定のファイル上限は32 MiB、Undoの予算は16 MiBです。検索・置換は文字列検索で、正規表現には対応しません。
読み込みと保存は別スレッドで行い、Escで読み込みや置換開始前の保存を中止できます。
下書きによる復元にはサイズ・ファイル名の対象外条件があり、書き込みの成功が必要です。
[設定](configuration.md)を参照してください。

エディターの内蔵の色分けに加え、任意のTree-sitter文法パックでエディターとプレビューを色分けできます。
dotenvは内蔵の字句解析を使います。対応形式、導入方法、信頼性の確認は
[シンタックスハイライト](syntax.md)を参照してください。Vimモードには演算子、移動、テキストオブジェクト、
Visualモード、レジスター、マクロ、`.`があります。Exの範囲指定、マーク、`:s`には対応しません。

Markdownファイルは自動モードでは端末幅100桁以上でライブプレビューを表示します。
`Alt+M`で切り替え、`[editor] markdown_split=auto|on|off`で既定の動作を指定します
(`on`は60桁から)。脚注、数式、フロントマター、コードブロック内の構文色分けは表示しません。

Gitの作業ツリーでは、各行に`M`変更、`U`未追跡、`A`追加、`D`削除、`R`名前変更、`!`競合を表示します。
ファイル名は、右に出る文字と同じ色になります。変更されたファイルを(深い階層も含めて)含むフォルダーにも色が付きます(`[git] folder_color`)。
エディターは100桁以上でHEADと現在のバッファの差分を読み取り専用で表示でき、未保存の編集も反映します。
Windows側ではPATH上の`git.exe`、WSL側では`wsl.exe`経由でディストリビューションの`git`を使います。
その環境のGitがなければ、別のバックエンドは試しません。問い合わせは非同期の読み取りコマンドです。
ステージ、コミット、pushの操作画面はありません。
MarkdownプレビューがGitペインより優先されるため、差分を見るには`Alt+M`でプレビューを隠します。
HEADの内容と、行を結合した編集テキストは、それぞれ4 MiBまでです。変更量が多い場合も差分の上限に達します。
比較ではCRLF/LFの違いと最終改行の有無を無視します。HEADのバイト列はエディターのUTF-8表現へ
変換しないため、UTF-8以外のファイルでは文字コードの違いが内容の変更として表示される場合があります。

## 検索と情報表示

- `/`は現在の一覧を絞り込みます。入力中のTabで配下の検索に切り替えます。
  条件は`ext:txt`、`size>10k`、`size<2m`、`newer:2026-10-01`、`older:2026-01-01`などです(日付はUTC)。
- `s`は現在の一覧のファイル名をファジー検索します。
- `F`はサイズ、先頭部分のSHA-256、全体のSHA-256で重複候補をまとめます。
  ごみ箱に送るファイルは自分で選びます。UIはグループ全体の削除を拒否しますが、
  他のプログラムによる変更に対する保証ではありません。
- `#`は指定したローカルファイルのSHA-256を計算し、`D`はフォルダーのサイズを集計します。
- `i`は詳細と、取得できるNTFSのリンク・ストリーム・ボリューム情報を表示します。
- `L`はRestart Managerでファイルを開いているプログラムを調べます。終了要求と強制終了には確認が必要です。
  保護されたプロセスや確認できないプロセスは拒否します。再試行でも通常の操作の検査をやり直します。

配下の検索、重複検索、ハッシュ計算、サイズ集計は上限を設けてワーカーで行います。
リンクや未対応の場所は対象外です。配下の検索と重複検索はローカルフォルダーでのみ使えます。
Escで中止します。結果画面の操作は[キー操作](keybindings.md)を参照してください。

## ファイル操作と外部ツール

作成、名前変更、コピー、同一・別ボリュームへの移動、ごみ箱への削除、一括名前変更を実装しています。
新規作成の名前に`test/hello`のように書くと、フォルダー`test`の中にファイル(フォルダーなら`hello`フォルダー)を作り、`test`がなければ先に作ります。途中に同名のファイルやリンクがあるときは入らず、`..`は拒否します。
コピーは既定でSHA-256による読み戻し検証を行い、`verify=none`の明示指定で無効にします。
別ボリュームへの移動はコピーを検証してから元をごみ箱へ送ります。
暗号化されたもの、リンク、オンライン専用のコピー元は拒否またはスキップします。
コピー元のACL、拡張属性、暗号化・圧縮の状態は保持しません。上書き時はコピー先のアクセス権を引き継ぎます。

同名ファイルがある場合はスキップ、両方を保持、上書きから選びます。
上書きは元のファイルを完全に削除し、ごみ箱やUndoから復元できません。
コピーは既存のフォルダーを統合しますが、移動では統合しません。
エディター・設定の置換保存は、`name~`から`name~9`までの最初の空き名に原本を保持し、
9個すべてが埋まっていれば拒否します。Save Asは上書きしません。[既知の制限](safety.md)を参照してください。

`J`は実行中の直近32件の変更を表示します。Undo(`u`)は最大16件を保持し、識別情報と移動先の確認を条件に、
名前変更、同一ボリューム内の移動、新しく作られたコピー、完了した一括名前変更を戻せます。
ごみ箱への削除、作成、上書き、別ボリュームへの移動は戻せません。
一括処理の中止時は名前の復元を試み、未完了なら結果に示します。履歴とUndoは永続化しません。

`Y`はWindowsクリップボードにファイルのコピーを渡し、`V`はコピーを取り込みます。
切り取り、仮想ファイル、複数のコピー元フォルダーからの取り込みは拒否します。
自動テストには受信プログラムを使います。実際のExplorerとの連携は未確認です。
`!`は現在のローカルフォルダーでWindows Terminal、Windows PowerShell、cmd.exeの順に起動を試みます。
外部アプリで開く際は識別情報を検査し、実行可能な形式や未知の形式では確認を求めます。
作業フォルダーは既定で専用の中立領域を使います。

## WSLとSFTP

移動(`g`)は`wsl:<distribution>[/path]`と`sftp:<host>[/path]`を受け付けます。
WSLではローカルコピーエンジンに必要なWindowsの識別情報を得られないため、専用の処理を使います。
作成、名前変更、コピー、同じディストリビューション内の移動、削除、エディターの保存に対応します。
WindowsとWSLをまたぐコピーはできますが、移動はできません。
WSLのコピー処理には20000項目、深さ48階層、データ256 MiBの上限があります。コピー・移動では既存の名前を置き換えません。
エディター保存ではバックアップを残して元のファイルを直接書き換えるため、クラッシュで内容が途中までになる可能性があります。
[安全性](safety.md)を参照してください。
WSLの削除は別の確認を経て完全に削除し、ごみ箱は使いません。
WSLのUndoは直近の作成、名前変更、移動に対応します。コピーはLinuxのモードや所有者を保持しません。

SFTPは自分の`ssh.exe`とSSH設定を使います。承認済みのホストキーと、
SSHが対話なしで使える認証（鍵認証など）が必要です。パスワードや対話式認証の入力はできません。
読み取り専用で、閲覧とエディターでの表示に対応します。サーバーへの保存・変更はできませんが、
Save Asで新しいローカルのWindowsファイルとして保存できます。
どちらもローカルのWindowsフォルダーとは安全性やメタデータの制約が異なります。
外部環境での確認は[手動検証](manual-verification-procedures.md)を参照してください。
自動テストの結果は、すべてのディストリビューションやサーバーでの動作確認ではありません。

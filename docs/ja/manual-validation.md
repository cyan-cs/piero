# 手動検証

ファイル操作、インストールと削除、中断のテストには、所有を確認した、捨ててよいWindowsのVM、隔離した
仮想のテスト用ディスク、元に戻せるスナップショットを使います。ホストの個人のドライブやユーザーの共有は
接続しません。最初に、VMとディスクの識別子、スナップショット、EXEのハッシュ、許可した範囲を記録します。

端末を起動しなくても、合成したテスト用の試料は準備できます。

```powershell
cmake --build out/dev --target piero wic_proto
python tools/prepare_manual_validation.py --output out/manual-new --executable out/dev/piero.exe
```

準備したランチャーは、実際のWindows Terminalの中で実行します。例:

```powershell
.\out\manual-new\run-terminal.ps1 -Profile standard -Graphics auto -Language en
```

専用の設定と状態フォルダーを使います。生成した結果はNOT RUNで始まるので、
各項目を観測してから記入してください。ファイル操作には前述の使い捨てVMが必要です。
移動、先読み、日英の切り替え、IME/JIS、すべてのキーマップ、プレビューの文字コード、画像とPDF、Sixelとフォールバック、
リサイズ、ダイアログの重なり、長時間の放置、速いスクロール、端末の復元を確認します。
モデルやConPTYによるテストは、目で見て確かめることの代わりにはなりません。

確認したVMで、操作の前と後の、原本、宛先、ADS、同一性、バックアップ、一時ファイル、復旧の状態を
比べます。キャンセル、一時停止、アクセス拒否、差し替えによる競合、壊れたジャーナルも確認します。
禁止されている操作は拒否されなければならず、テストのために有効にしてはいけません。プロセスのクラッシュ、
強制終了、OSのクラッシュ、VMの電源断は、それぞれ別のテストです。結果が食い違ったら止めて、自動では清掃せず、
ディスクとログを残してください。

インストールと削除では、ユーザーPATHが存在しない場合、すでにある場合、外から変更された場合、重複や同等の項目、
レジストリ文字列の型、すでにあるインストール先、個人の設定が残ることを確認します。ポータブル版とインストール版が同じバージョンを
返すことも確かめてください。準備用のスクリプトを動かしても、実機にインストールしたことにはならず、実際の通信を確かめたことにもなりません。

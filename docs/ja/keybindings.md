# キー操作

## 現在のプロファイル

`?`と設定には、コマンド表から生成した現在の割り当てを表示します。
このガイドには、基本の操作と、組み込みキーの全一覧を生成する手順をまとめています。
キーボードプロファイルを指定していない場合はStandardです。初回設定ではNano/Vimも選べます。NanoやVimを選んだあとは、Standardのコピー・移動のキーが
使えるとは限りません。

| Standard | 操作 |
| --- | --- |
| `j` / `k`, 矢印キー | カーソル |
| `h` / `l` | 親へ戻る・ディレクトリへ移動 |
| `b` / `f` | 戻る・進む |
| Space / Esc | マーク。Escは一度に一つずつ取り消します: 実行中の集計、マーク、フィルター、コピー・移動の待機の順です |
| `/`, `.`, `r` | 絞り込み・隠し項目・再読み込み |
| `/`のあとTab | このフォルダー以下を検索 |
| `F` | 内容が重複するファイルを検索 |
| `g`, Ctrl+L | パス移動。Ctrl+Lは現在のパスを選択した状態で開く |
| `g` → `wsl:<distribution>[/path]` | WSLの閲覧と操作 |
| `g` → `sftp:<host>[/path]` | SFTPを閲覧（読み取り専用） |
| マウス | クリックで選択、ダブルクリックで開く、ホイールでスクロール |
| 文字の貼り付け | 検出した貼り付けは文字として扱う（制限は後述） |
| `i`, `v`, `P` | 詳細・全画面プレビュー・明示的なプレビュー要求 |
| `e`, `,`, `?`, `q` | エディタ・設定・ヘルプ・終了 |
| `y` / `x`, `p` | Copy・Moveを登録後、貼り付け |
| Delete, `u` | 確認後にごみ箱へ。名前変更・移動・コピー・一括名前変更のUndo(最新の変更から、確認後に実行。一括名前変更は全項目を再検査し、復元の失敗は結果に表示) |
| `J` | 変更履歴を表示し、失敗した転送を再試行 |
| `?` | 分類（左右キー）ごとのヘルプ。上の検索ボックスに文字を打つと、キー・操作名・説明で検索します。件数を表示し、一致した部分に色を付けます。キーがその文字そのものの操作を先頭に並べ、各行に分類名を出します。Escで検索を解除し、もう一度で閉じます。プレビューから開くとプレビューのキーから始まります |
| `B` | カーソルのファイルのバックアップ(`name~` から `name~9`)を表示し、エディタで開く、またはごみ箱へ送る |
| `Y` | 選択したパスをコピーとして渡す |
| `V` | クリップボードのファイルをこのフォルダーへコピー |
| `L` | ロックの調査、終了要求、操作の再試行 |
| `s` | 文字が順に現れる名前を検索 |
| `M` | パターンで名前を変更（実行前に一覧で確認） |
| `!` | 現在のローカルフォルダーで端末を開く |
| `#` | 指定したファイルのハッシュを計算 |
| `t`、`w` | タブを開く・閉じる（保存しない） |
| `[`、`]` | 前・次のタブへ移動 |
| `m`のあとに文字キー、`'`のあとに文字キー | 文字キーにフォルダーを保存・呼び出し |
| `D` | フォルダーのサイズを集計（Escで中止） |
| `z`, `C` | キューの一時停止・再開、キャンセル |
| `a`, `%`, `d`, F2 / `R` | 作成メニュー・ファイル・ディレクトリ・名前変更 |

## 操作の詳細

### 配下の検索

フィルターをこのフォルダー以下に広げます。入力した文字列がこのフォルダーの下のフォルダーの検索になり、近いフォルダーから順に、見つかったそばから結果画面に表示します。

単語(すべてが名前に含まれること、大文字小文字は区別しません)、`"a b"`、`ext:txt`、`size>10k`、`size<2m`、`newer:2026-10-01`、`older:2026-01-01`(日付はUTC)が使えます。

結果画面の操作: 上下、PgUp/PgDn、Home/End、Spaceで印、Ctrl+Aですべてに印、Enterでその結果をそのフォルダーで表示、`y`と`x`は1つのフォルダーの結果のコピーと移動、Deleteは任意のフォルダーの結果を、確認を1回してごみ箱へ送ります。Escで検索を止め、もう一度Escで結果画面を閉じます。

### 重複ファイル

このフォルダー以下で内容が同じファイルを一覧します(サイズとSHA-256が同じもの。サイズ、先頭64 KiB、ファイル全体の3段階で調べます)。結果画面にグループが並び、各ファイルにはグループを示す`[n]`と入っているフォルダーが付きます。Spaceで要らないコピーに印を付けます(グループの最後のファイルには印を付けられません)。

Deleteは印のついたもの(なければカーソル下のもの)を、確認を1回してごみ箱へ送り、グループ全体は決して送りません。Enterでファイルをそのフォルダーで表示します。Ctrl+A、`y`、`x`は使えません。Escで止め、もう一度Escで閉じます。検索自体はファイルを読み取るだけです。コマンド`fm.dupes`。

### WSLの操作

WSL のディストリビューションへ移動します。そこでは作成・名前変更・コピー・移動(同じディストリビューション内)・削除・保存ができます。既にある名前は上書きせず、削除は完全削除です(ごみ箱はありません)。コピーでは更新日時の引き継ぎを試み、失敗は警告します。Linuxの権限と所有者は引き継ぎません。

`u` で直前の作成・名前変更・移動を取り消せます。

### SFTPの閲覧

ご自分の `ssh.exe` でサーバーを閲覧します(ホスト名は ssh 設定にあるもの。ホスト鍵は登録済みであること)。エディターはサーバーに書き戻せませんが、Save Asで新しいローカルのWindowsファイルとして保存できます。

### マウス操作

エントリをクリックするとカーソルがそこへ移り、ダブルクリックで開きます。親フォルダーの列のエントリをクリックするとそこへ移動します(フォルダーなら入り、ファイルならそのフォルダーで選択します)。ホイールはポインターの下にある一覧またはプレビューを 3 行ずつ動かします(エディタではポインターを使いません)。

### はい・いいえの質問

質問には`Y`または`N`を入力して答えます。表示直後の短い間は、キーを無視します。
単純なはい・いいえの質問では、左または上で「はい」、右または下で「いいえ」を選べます。
選んだ方には`>`が付き、Enterで決定します。Enterだけの場合と、Escは、いつでも「いいえ」です。
選択は「いいえ」から始まります。ほかの答えがある質問(スキップ、上書きなど)は、文字キーだけで答えます。

### テキストの貼り付け

貼り付けと検出したキーは、ファイル一覧ではコマンドとして実行されません。入力欄では文字として入りますが、貼り付けた Enter と Tab は確定せず、その後の行も取り込みません。確認の質問にも答えません。コンソールがブラケット貼り付けの印を渡さないため、届き方で貼り付けを見分けます。

1 回の読み取りに異なるキーが 3 つ以上(または Enter と別のキー)あるものと、その後 30 ms 以内に続くものです。1 文字や 2 文字の貼り付けは、入力と区別できません。貼り付けた改行は 1 回として数えます。

### 履歴と再試行

このセッションの直近32件の変更の履歴: コピー・移動・削除のジョブ(失敗はすべてフルパスつき)、名前変更、同一ボリューム内の移動、新しいファイルとフォルダー、一括名前変更。各行の下に、「uで元に戻す」、「新しい変更を戻したあとで元に戻せます」、「元に戻しました」、「もう元に戻せません」、「元に戻せません」とその理由が出ます。

ここでの`u`は一覧でのUndoと同じです(最新の変更を、確認のあとで)。`r`で失敗したコピー元だけを転送スロットに戻し、その移動先を開きます（貼り付けでは確認をすべてやり直します）。履歴自体はディスクに保存しません。Undoや再試行した操作ではファイルを変更します。

### Windowsクリップボードへのコピー

選択したファイル(なければカーソル下)をコピーとして Windows のクリップボードへ渡す。エクスプローラーなどが貼り付けられる。渡すのは名前だけで、読み取りも複製も変更もしない。検証はテスト用の受け手で、実際のエクスプローラーでは未確認。

### Windowsクリップボードからの貼り付け

Windows のクリップボードのファイル(エクスプローラーのコピー)を、通常のコピーでこのフォルダーへ貼り付ける。検査も、同名があるときの質問も同じ。エクスプローラーの切り取り、複数フォルダーのファイル、ネットワーク共有、実ファイルでないものは、拒否して何も変更しない。`X`(エクスプローラーへの切り取り)は未実装。

`Ctrl+C` はプログラムの中断で、`Ctrl+V` は Windows Terminal が使うため、ファイルのクリップボードは Shift 付きのキーにしている。

### ファイルを開いているプログラム

Restart Managerで、対象のファイルを開いているプログラムを調べます。
コピー・移動・削除・名前変更・エディター保存の失敗後や、カーソル下のファイルについて利用できます。

| キー | 操作 |
| --- | --- |
| `R` | 再調査 |
| `C` | プログラムに終了を要求 |
| `K` | 二段階の確認後に強制終了 |
| `T` | 失敗した操作を通常の入口へ戻す。検査をやり直し、自動では実行しない |
| `Up` / `Down` | プログラムを選択 |
| `Esc` | 画面を閉じる |

piero自身、サービス、重要・保護・システムプロセス、別ユーザーのプログラム、
PIDと起動時刻を照合できないプロセスは強制終了できません。コマンドIDは`fm.locks`です。

### ファジー検索

この一覧の名前を数文字であいまい検索する(Nano では `Ctrl+W` でも可)。入力に合わせて、近い順に結果が並び、一致した文字には下線が付き、カーソルは選んだ結果に付いてくる。文字は順に現れればよい(`cfg` で `config_file.go` が見つかる)。大文字小文字は区別せず、ひらがなでカタカナも見つかる。

アクセントや合成文字の同一視はしない。上下で選び(最初の 64 件を過ぎると続きを読み込む)、Enter でその項目にカーソルを置いたまま終わる(開かない)。Esc でカーソルとスクロールを元に戻す。ファイルは読まず、何も変更しない。`/` は従来どおり絞り込み(文字を含まないものを隠す)

### 一括名前変更

選択した項目(なければカーソル下)をパターンで一括名前変更する。先に確認画面が出る。項目: テンプレート(`{name}` 元の名前、`{n}` / `{n:4}` 連番)、検索、置換、開始番号、増分、名前の大小文字、拡張子の大小文字。`Tab` / `Shift+Tab` で項目移動、`Enter` で確認画面、`Esc` で中止。

確認画面は全行を 変更前 -> 変更後 で並べ、拒否される行にはその理由が付く。拒否される行があるか、変更するものがないときは実行できず、何も変更しない。問題のない確認画面で `Enter` を押すと質問が一度出る(短い待ちの後に `y`)。実行中の `Esc` は中止と名前の復元を要求します。

戻せなかった名前がないか結果を確認してください。結果が「完了」になるのは、すべての名前を変えられたときだけ。クラッシュすると状態フォルダー(`batch\`)に記録ファイルが残り、次回起動時に復旧するか尋ねる(勝手には行わない)。完了した一括名前変更は、識別情報と名前を再確認したうえで`u`で元に戻せます。

コマンド名 `fm.bulk_rename`。

### 端末を開く

Open Terminal Here: 画面に出ているフォルダー(今のタブのフォルダー。カーソル下の項目ではない)で新しいターミナルを開きます。起動できれば Windows Terminal(`wt.exe -d`)、だめなら Windows PowerShell、さらにだめなら cmd.exe です。

ローカルドライブのフォルダーだけで、共有、アーカイブ、SFTP、WSL、260文字以上のパス、なくなったフォルダー、入れないフォルダーはメッセージを出して断ります。管理者権限は要求せず、pieroはそのまま動き続けます。コマンド`fm.terminal`。[機能](features.md)を参照。

### SHA-256

カーソル下のファイルのSHA-256を、要求したときだけ計算します。閲覧中に自動でハッシュを計算しません。状態行に進み具合と、続いてダイジェストが出ます。`Esc`で中止します。詳細ウィンドウ(`i`)には、そのファイルが読み取ったときと同じ(サイズと最終更新時刻で判断)である間、ダイジェストが出ます。

読み取り中に変わったファイルにはダイジェストを出しません。フォルダー、リンク、ローカルドライブにないファイルは対象外です。

### タブ

このフォルダーで新しいタブを開く、またはこのタブを閉じます。タブはフォルダーとそのカーソル位置の名前で、最大8個です。タブ帯はタブが2つ以上あるときだけタイトル行に出ます。タブはこの実行の間だけのもので、保存されません。

### タブの切り替え

前のタブ、次のタブへ移ります(端では反対側へ回ります)。StandardとVimのプロファイルでは、Ctrl+LeftとCtrl+Rightも同じです。NanoではCtrl+Rightがフォルダーに入るキーなので、角括弧だけです。

### 場所の保存

いるフォルダーをaからzの文字に保存する、文字に保存したフォルダーへ移る。`'`は先に保存済みの場所を一覧します。Escや別のキーで中止します。場所は設定ファイル(`[places]`)に書かれ、次の実行にも残ります。

### フォルダーのサイズ

一覧にあるすべてのフォルダーの大きさを数える(各フォルダーの行の右端に表示。Esc で中止すると、そこまでの値が `+` 付きで残る。`r` で消える)。リンクは辿らない。詳細(`i`)にはファイル数、フォルダー数、バイト数が出る。

## Nano・Vim・Custom

Nanoは矢印またはCtrl+P/N、Enterで開く、Leftで親へ、Ctrl+Fで絞り込み、
Ctrl+Gでヘルプ、Ctrl+Xまたは`q`で終了します。Alt+6でCopy登録、Ctrl+KでMove登録、
Ctrl+Uで貼り付け、Alt+UでUndoします。`hjkl`や`y/x/p`はNanoの移動・転送キーではありません。
Vimでは`gg`、`G`、9999までの回数、`yy`でCopy、`dd`でMove（削除ではありません）、
`p`で貼り付け、`:`コマンドを追加します。連続キーの期限は1.5秒です。
コマンドラインにシェル呼び出しや任意プログラム実行はありません。
CustomはNano/Vimを基にし、競合や端末で区別できないキーを拒否します。

## エディタと設定

エディタはCtrl+Sで保存、F2でヘルプです。PieroはCtrl+X/Esc、NanoはCtrl+Xで閉じます。
Ctrl+Fで検索、PieroはCtrl+H、NanoはAlt+Rで置換します。Undo/RedoはPieroがCtrl+Z/Y、
NanoがAlt+U/Eです。Vim Normalは`i`で挿入、Escで戻り、`:w`で保存、
`:wq`は保存成功時だけ閉じます。`:q!`はそのバッファだけを破棄します。
エディタの`dd`は行の切り取りで、Move登録を行うファイルマネージャーの`dd`とは異なります。エディタの`d`は続く移動を待ちます。
クリップボードやバッファの文脈別操作は現在のヘルプを確認してください。
設定はCtrl+Sで保存し、Esc時の変更確認には`s`/`d`/`c`で答えます。
確認画面の文字に従ってください。エディタと設定の短い質問(変更の保存、再読み込み、削除、リセット)は、
文字キーのほか、上下キーで選んでEnterで答えられます。選択は常にキャンセルから始まるので、
Enterだけでは何も保存・破棄されません。IMEが有効でも文字キーを打たずに答えるための方法です。
全角の英字、かな、IMEが処理中のキーは質問の答えになりません。
ファイル操作の確認は、画面に表示された確認用の文字で答えます。Enterは中止です。
IMEとJISでの文字キーの判定は、まだ実際の端末で確かめていません。

## Customの設定

設定のキーボード画面から割り当てを変更できます。設定ファイルでは
`[keyboard] profile=custom`でCustom、`[keyboard.custom] base=nano|vim`で基になるキー配置を選びます。
変更は`[keyboard.custom.<context>]`に記述し、`fm.nav.down`などのコマンドIDをキー、
`k, Up`などのキー文字列を値にします。現在のNano/Customの既定値には
`[keyboard] bindings_version=2`を使います。古い版の設定では、従来の移動キーを意図的に保持する場合があります。
生成する一覧は文脈名、コマンドID、既定の割り当てを示し、保存した変更は反映しません。
編集後は実行中のアプリのヘルプを確認してください。ファイルの規則と検証は[設定](configuration.md)を参照してください。

カンマ区切りは代替キー、`g g`などの列は連続したキー入力です。未完の列はEscで取り消します。
回数指定は対応するVimの移動操作に限り、Copy/Move/Recycle/貼り付けには使えません。
Ctrl+I/Tab、Ctrl+M/Enterなど、端末が同じ入力として送るキーは個別に割り当てられず、Ctrl+Cも割り当てできません。

## Vimのコマンドライン

ファイルマネージャーでは`:`でコマンドラインを開きます。構文は次のとおりです。

```text
:go <path>
:sort name|size|modified|extension [asc|desc]
:set hidden on|off
:filter <text>
:clear-filter
:reload
:settings
:help
:q
```

空白を含むパスは引用符で囲みます。作成日時での並べ替えは提供しません。
終了時は通常どおり実行中のジョブを確認します。`:!`やシェル実行は利用できません。

エディタでは`:w`、`:wq`、`:q`、`:q!`、`:replace`、`:buffers`、`:bnext`、`:bprev`も使えます。
`Alt+M`で、`.md`ファイルのMarkdownプレビューペインを出し入れします(標準・Nano・Vimキー、Vimは通常モードも挿入モードも。Vimは`:preview`も)。コマンドは`ed.md_preview`で、Customで割り当てを変えられます。
通常の終了では変更を確認し、強制終了で破棄するのは現在のバッファだけです。
ノーマルモードでは`d`、`y`、`c`に続けて移動（`w`、`b`、`e`、`$`、`0`、`h`、`l`、`j`、`k`、`G`、`gg`、文字を伴う`f`・`t`・`F`・`T`、`iw`・`aw`・`i"`・`a(`・`i{`などのテキストオブジェクト、または同じ文字でその行）を指定でき、
前に回数も付けられます（`3dd`、`d2w`）。`D`と`C`は行末までです。
ビジュアルモード（`v`、`V`）では移動キーで選択し、`d`、`y`、`c`で操作します。
コピー・切り取り・貼り付けの前に`"a`でレジスタを選び、`qa`から`q`までの操作を記録して`@a`で再生します。
大文字（`"A`）にするとレジスタへ追記します。`.`は直前の変更を繰り返します（回数を付けるとその回数分）。
未対応のVimの`:s`構文の代わりに`:replace`を使ってください。

## エディター互換性の契約

比較基準はVim 9.1、patches 1–2081（MSYS2、2026-01-13ビルド）とし、`vim -Nu NONE -N -n -i NONE -es`で起動します。固定設定は`nocompatible nomodeline noswapfile noignorecase whichwrap=b,s virtualedit= selection=inclusive`です。回帰テストには実測した本文とバイト単位のカーソル位置を固定し、CIにVimの導入を要求しません。Nanoの挙動はGNU nano 9.3のマニュアルと照合し、nano実行ファイルとの比較テストは行っていません。

Vim Normalのカーソルは文字上に置きます。左右移動は行境界で止まり、`0`は列の先頭、`$`は最終文字を指します。`gg`/`G`は最終改行後の内部的な挿入用行へ移動しません。演算子の前後の回数を反映し、VisualのテキストオブジェクトはVisualモードを維持します。検索の初期値は大文字小文字を区別し、リテラル一致の先頭へ移動します。続く検索はその一致より先へ進みます。

Vimの無名・名前付きレジスタは、本文とは独立に文字単位・行単位の種別を保持します。改行を含む文字単位レジスタもカーソル位置へ貼り付け、行単位レジスタは行全体の上または下へ貼り付けます。空の名前付きレジスタでは何も挿入しません。レジスタとNanoのcutbufferは編集セッションが保持し、Windowsクリップボードから分離します。NanoとVim Insertでは`Ctrl+Insert`と`Shift+Insert`で明示的にクリップボードを利用します。Standardの従来のクリップボード動作は維持します。

Vimの一連のInsert操作は改行を含めてまとめ、Escまたは矢印移動でUndoの単位を区切ります。change演算子と続く挿入は同じ単位です。貼り付け、回数付き削除、その他の範囲編集はそれぞれひとつの単位で、マクロ再生では構成する各編集の単位を維持します。Redoは同じ単位と最終カーソル位置を復元します。開いている単位が設定済みの履歴容量を超える場合は、次の編集を明示的に失敗させ、完了分をまとめてUndoできる状態を保ちます。単独の記録が容量を超えることは従来の履歴方針どおり許可します。確保・編集失敗では本文、カーソル、選択、レジスタ、cutbuffer、Undo/Redoを保持し、複数記録のUndo/Redo失敗では適用済み部分も戻します。Undoでレジスタの内容は巻き戻しません。

Nanoでは選択なしの`Ctrl+K`を連続して実行するとcutbufferへ追記します。別の編集命令、移動、コピー、貼り付け、プロンプト、バッファ切り替えを挟むと連続状態を終了し、次の切り取りではcutbufferを置き換えます。画面サイズ変更とキー解放では連続状態を維持します。選択範囲の切り取りはcutbufferを置き換えます。`Alt+6`はコピーして置き換え、マークを解除します。`Ctrl+U`はVimの行単位属性を付けずカーソル位置へ挿入します。`Ctrl+A`は列の先頭へ移動し、`Ctrl+Delete`は次の単語を削除します。

Nanoの`Ctrl+O`は現在のファイル名を初期値とします。選択範囲があっても本文全体を保存し、選択状態を保持します。現在のパスでEnterを押すと元ファイルの基準情報を使い、通常の検査付き保存を行います。別名は排他的に新規作成し、既存の保存先は上書きせず拒否します。読み取り専用バッファは元のパスへの保存を拒否しますが、別の新規名へのコピーは許可します。中止・失敗時はバッファの識別情報と編集状態を保持します。競合、同一性、リンク、文字コード、復旧を含むpieroの保存規則を適用し、選択範囲だけの書き出しと強制上書きは実装しません。

長い単語の探索は64 KiB単位で実行を分割します。Vimの単語移動とその演算子、Nanoの単語削除、マクロ・ドット再生では後続入力の順序を維持します。セッションのキュー上限は64イベントです。満杯ではイベントを受け取らず`WF_ES_BUSY`を返し、呼び出し元は上限付きのバッチを保持して、空きができるまでコンソールを読みません。貼り付け由来ではないEscをキューが受け取ると、未完了の探索・再生を中断して状態を表示し、キュー内の入力は消しません。保持した入力は変更前のカーソルから到着順に処理し、Escとそれに続く入力も処理します。満杯時のEscは受け取れるまで呼び出し元が保持します。バッファ、本文の世代、カーソルが変わった探索結果は無効化し、中断を通知します。保持した入力はその時点の編集状態に対して順に処理します。最後のバッファを閉じた後の残りの入力も呼び出し元へ順に返します。

これらのプロファイルは文書化したpieroの部分集合であり、Vim/nano全体の再現ではありません。Vim Normalでも貼り付け本文を挿入し、検索にはpieroのリテラル検索を使います。非ASCII文字の単語判定もpieroの既存規則に従います。ファイル一覧のキーと操作のステージングは編集命令から分離します。Ex全体、正規表現検索、矩形レジスタ、Nanoの追加命令、実端末・IMEでの等価性は今回の範囲外です。引用符・括弧のテキストオブジェクトなど、既存のすべての探索を分割実行へ変更したわけではありません。

## 全組み込みキー一覧の生成

テストを有効にして構成済みの開発ビルドで実行します。

```powershell
cmake --build out/dev --target dump_keys
out/dev/dump_keys.exe
```

使用中のビルド先が異なる場合は置き換えてください。診断用ターゲット`tests/dump_keys.c`は、
Standard/Nano/Vimのファイルマネージャー、プレビュー、エディタの各文脈を、コマンド表とキーマップから直接出力します。
出力は英語で、各行はキー、動作、設定用コマンドIDです。`(none)`はその文脈で既定の割り当てがないことを示します。
Customの変更、設定・ダイアログのキー、実行中のアプリの状態を出力するものではありません。
出力をファイルに保存する場合はignore対象の`out/`配下を使い、ルートに別のキー一覧を複製して管理しないでください。

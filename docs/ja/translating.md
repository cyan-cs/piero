# 翻訳

[English](../en/translating.md)

UTF-8のINIファイルを編集すれば、再ビルドせずに翻訳を変えられます。
`languages/en.ini`または`languages/ja.ini`をコピーして`fr.ini`にし、
`[language]`の`code`を`fr`に、`name`をその言語の表示名に変更します。
コードは小文字のASCII英数字とハイフンで区切ったサブタグで、先頭は英字、最大31バイトです。
ファイル名はコードと同じにしてください。`auto`は予約語です。
表示名はUTF-8で最大128バイトです。同じ名前の言語を見分けられるよう、選択画面にはコードも表示します。

置き場所は、実行ファイルの横の`languages/`か、
`%LOCALAPPDATA%\piero\languages\`です。同じコードがあれば、ユーザー側の値が優先されます。
一部だけを書いたファイルは配布版の翻訳を引き継ぎ、どちらにもないキーは、生成済みの非常用の英語になります。
各ファイルに`code`と`name`が必要です。`plural`は省略できます。`one-other`は単数のときだけ単数形、
`none`は常に複数形を使います。一部を上書きするファイルで`plural`を省くと、配布版の規則を引き継ぎます。
複数形の規則は、二つの形に限られ、任意の規則には対応していません。

```ini
[language]
code = fr
name = Français
plural = one-other

[messages]
MSG_SETTINGS_TITLE = Paramètres
```

設定 → 一般 → 言語で選び、Ctrl+Sで保存します。言語は、起動時と設定画面を開くときに検出し、
言語を選ぶときにそのファイルを読み直します。通常のファイル操作中は、ファイルの監視も定期的な読み込みもしません。
同じセッションの途中でその言語のファイルを削除すると、コードは保持したまま英語に戻ります。次の起動時に、設定した言語の
ファイルがなければ「利用できない」と表示して英語を使い、起動は止めません。コードを保持するので、
英語を明示的に選んだ場合も、別のコードとして保存できます。
言語フォルダーを開く専用のメニューはありません。上のパスを使ってください。

改行はLFとCRLF、先頭のUTF-8 BOM、`;`または`#`で始まるコメント行（省略可）が使えます。
最初の`=`でキーと値を区切り、それ以降の`=`、`;`、`#`は、ふつうの文字として扱います。
値の前後の空白は取り除かれるので、残したい空白は`\s`と書きます。`\\`はバックスラッシュ、
`\n`は改行です。複数行を表示する画面では改行され、1行の入力欄では`?`と表示されます。
それ以外のエスケープは使えません。同じセクションでキーが重複すると、ファイル全体を拒否します。
未知のキーは無視します。構文が正しくない、UTF-8として不正、NULや端末制御文字を含む、プレースホルダーや
メタデータが正しくない、というファイルは拒否し、配布版または非常用の英語を使います。

`{0}`〜`{3}`の識別子と、必要な引数の数は変えないでください。`{{`は、開き波括弧そのものを表します。
差し込む値が文字列か整数かは呼び出し側で決まっていて、翻訳側から変換や型の指定を足すことはできません。
翻訳をprintfの書式として使うことはなく、`%n`の変換指定は拒否します。
`en.ini`の`[arguments]`が、ビルド時の引数の数の原本です。ほかのファイルでは省略できますが、
引数の数は変えられません。既存の`MSG_*`キーの名前は変えないでください。
製品のメッセージを増やすときは、英語の末尾にキーと引数の数を足し、日本語にも訳を加えます。
言語を追加するのに、CやCMakeを編集する必要はありません。元になるのはINIだけで、生成されるヘッダーは派生物です。

上限は、英語と日本語を含めて32言語、各ディレクトリ64候補、各ファイル1 MiB、8,192個のキー、
デコード後の値はUTF-8で4,096バイトです。シンボリックリンクやreparse pointのファイルは拒否します。
読み込み中は書き込みと削除の共有を許さず、サイズと時刻も照合します。ほかが書き込みハンドルを持っている場合は
フォールバックします。切り替えたあとも、返した文字列を保持できるように、重複を除いたセッション用の領域を
最大16 MiBまで使います。上限に達したときは、無制限に保持したり無効なポインターを使ったりせず、フォールバックし、
再起動で解放されます。翻訳文は、操作の可否、同一性の確認、ハッシュ、復旧の判断に影響しません。

開発ビルドの付属ツールにはPython 3.10+を使い、INIからIDと非常用の英語を生成します。CMakeが使えないshimを
選んでしまう場合は、`-DPython3_EXECUTABLE=C:/path/to/python.exe`で実体を指定してください。
次の検査も使えます。

```powershell
python tools/check_languages.py
python tools/check_languages.py path/to/fr.ini
```

ZIPとインストーラーには`languages/en.ini`と`languages/ja.ini`が入ります。
実行ファイルを移動するときは、このディレクトリも一緒に移してください。
`%LOCALAPPDATA%\piero\languages\`にあるユーザーの翻訳は、パッケージによる配置、更新、削除の
対象になりません。通常の利用にPythonは要りません。

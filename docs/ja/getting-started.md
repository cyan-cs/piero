# 導入

## インストールと起動

対象環境はWindows 11 x64です。Windows 10での動作は未検証で、インストーラーには
Windows 11（build 22000以降）が必要です。
[GitHub Releases](https://github.com/cyan-cs/piero/releases)でパッケージの公開状況を確認してください。
ポータブルZIPは新しいフォルダーに全体を展開し、インストーラーがある場合は画面の案内に従います。
`languages/`、`LICENSE`、`LICENSES/`は`piero.exe`と一緒に置いてください。
配布パッケージはCRTを静的にリンクするため、Visual C++ランタイムの別途導入は不要です。
Gitが必要なのはGit連携を使う場合だけです。

展開先のフォルダーでターミナルを開き、起動します。

```powershell
.\piero.exe
```

別のフォルダーで始めるには、`piero.exe C:\Work`のようにパスを指定します。
パッケージが公開されていない場合は[ソースからのビルド](development.md#ソースからのビルド)を参照してください。

## 初回起動

最初は試用用のローカルファイルで操作を確認してください。セットアップで言語、キーボードプロファイル、
テーマを選びます。`piero --setup`でやり直し、`piero --language ja`で今回だけ日本語にできます。
`?`で現在のキー操作、`,`で設定を開きます。

Standardキーでは矢印で移動、Spaceで選択、`e`で編集、`q`でファイルマネージャーを終了します。
コピーは`y`を押し、移動先で`p`を押します。ほかのプロファイルでは異なるため、[キー操作](keybindings.md)を参照してください。
重要なファイルを移動・削除・上書きする前に[安全性](safety.md)を確認してください。
上書きは元に戻せず、Undoの対象は実行中の一部の操作に限られます。

リリース確認のためGitHubへの通信を許可するかは、別の画面で確認します。既定では無効です。
取得するのはリリース情報だけで、ダウンロードとインストールは手動です。[更新](updates.md)を参照してください。

## 設定と保存データ

設定は通常`%APPDATA%\piero\config.ini`を使います。`--config <path>`には既存の有効なファイルが必要です。
ポータブル版でも設定はユーザープロファイルに保存します。
設定、下書き、任意のセッション復元については[設定ガイド](configuration.md)を参照してください。

ローカルの記録、下書き、作業ファイルは通常`%LOCALAPPDATA%\piero`に保存します。
古い`wfile`フォルダーだけがあれば引き続き使い、両方あれば`piero`を使って旧フォルダーの未解決の記録も確認します。
自動的な移行や削除は行いません。状態データを削除する前に、記録・バックアップ・原本を保管してください。
復旧警告を消すために状態フォルダーを削除しないでください。
[安全性](safety.md)と[トラブルシューティング](troubleshooting.md)を参照してください。

## プレビューと問題への対処

画像・PDFのプレビューは既定で有効で、AppContainerの隔離機能が必要です。
設定 > プレビュー > 画像で無効にできます。Sixelには対応する端末応答とピクセル寸法が必要で、
利用できない場合は文字セルで表示します。
プレビュー、保存エラー、復旧通知については[トラブルシューティング](troubleshooting.md)を参照してください。
パッケージの作成と、インストール・アンインストールで残っている検証は[パッケージ作成](packaging.md)に記載しています。

## コマンドラインの補助機能

`--help`と`--version`は英語で表示します。`--print-last-dir <new-file>`は、移動に成功して通常終了した場合に
BOM付きUTF-8で最後の場所を新規ファイルへ書きます。既存の名前は拒否します。
アーカイブ内の場合は、それを置いているフォルダーを記録します。
`--reset-terminal`は端末リセットを出力します。復旧コマンドと、利用できない`--purge-state`については
[安全性](safety.md)を参照してください。

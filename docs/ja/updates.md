# 更新

最初の通常セッションで、GitHubへ安定版の確認を行うか尋ねます。既定は「今はしない」です。
選んだ内容は、通常の設定の保存処理で保存し、保存できてから自動確認を許可します。
設定がない、壊れている、または将来の形式のときは、自動で通信することは許可しません。

設定の「更新」には自動確認、今すぐ確認、現在のバージョン、最新の結果があります。
変更した設定はCtrl+Sで保存してください。自動確認が無効でも手動確認は利用できます。
初回の選択と、保存された設定は、同じキーを使います。

```ini
[updates]
enabled=false
consent_recorded=true
```

確認は別のワーカーで行い、UIスレッドは待ちません。失敗した試行も含めて、自動確認の試行を
ユーザーのレジストリに記録し、24時間に一回までに制限します。時計が巻き戻ったときや、
状態を読み取れないときは、自動確認を見送ります。手動の確認は、利用者が明示的に行う操作として扱います。
認証情報、Cookie、ファイル内容は送信しません。接続先は
`https://api.github.com/repos/cyan-cs/piero/releases/latest`だけで、リダイレクトは拒否します。
接続と読み取りにはタイムアウトを設け、応答は64 KiBまでに制限します。

厳密に解析して、より新しい安定版のセマンティックバージョンだと確認できたものだけを通知します。
ドラフト、プレリリース、不正または大きすぎる応答、古いバージョンは案内しません。
オフライン、非公開のリポジトリ、リリースがない、レート制限のときでも、起動は続けます。無効にすると、新しい
自動リクエストは止まり、すでに実行中の処理は、区切りのよいところでキャンセルします。
バックグラウンドで繰り返し確認することはありません。

ダウンロードとインストールは手動です。リリース情報や、同じサーバーにあるハッシュだけでは、
発行元が本物だという独立した証明にはなりません。署名付きの更新の検証、安全なバイナリの置き換え、
ロールバックは未実装なので、この版は更新ファイルをダウンロードも実行もしません。
メンテナーの[公式Releases](https://github.com/cyan-cs/piero/releases)と署名状態を確認してください。

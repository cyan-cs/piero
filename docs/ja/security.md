# セキュリティ方針

## 対応バージョン

この方針の対象は、このソースの開発プレビューです。この文書ではサポート対象の安定版を指定していません。
開発プレビューには既知の制限があり、応答期限や安全性を保証しません。
既知の制限は[安全性](safety.md)、残る実環境での確認は[手動検証](manual-validation.md)を参照してください。

## 報告方法

非公開の報告は、リポジトリのSecurityタブにある**Report a vulnerability**
(GitHub Private Vulnerability Reporting)から行ってください。メールアドレスなど、ほかの連絡先は
公開していません。非公開の報告機能を利用できない場合は、問題の詳細を書かず、
非公開の連絡手段を求めるだけの公開Issueを作成してください。
認証情報、個人のファイル名、文書、悪用手順を公開Issueへ記載しないでください。
最小限の破棄可能な再現データを使い、診断のパスを伏せてください。応答期限は約束しません。

## 対象範囲

ファイル操作の整合性、復旧、メタデータ、解析、端末出力、デコーダー隔離が対象です。
自動テストの成功は電源断時の永続性を認定せず、記録済みの競合を解消しません。
証跡と原本を保全してください。未確認の状態を削除したり、隔離ゲートを弱めたりして
問題を修復してはいけません。

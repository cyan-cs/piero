pieroは、テキストエディターを内蔵したWindows向けのファイルマネージャーです。
ターミナル上でフォルダーを横に並べ、キーボードで移動しながらファイルの確認や編集ができます。

> **開発プレビュー:** 重要なファイルには、事前に独立したバックアップを用意してください。
> 上書きしたファイルはpieroでは元に戻せません。実際の端末、インストーラー、電源断の検証は未完了です。
> [安全性ガイド](safety.md)を確認してからお使いください。

## 主な機能

- **ファイル管理:** コピー、移動、名前変更、一括名前変更、ローカルファイルのごみ箱への削除。一部の操作はUndoで戻せます。
- **フォルダー移動:** フォルダー階層の横並び表示、タブ、場所の保存、絞り込み、配下のファイル名検索。
- **プレビュー:** テキスト、Markdown、CSV/TSV、画像、PDF。対応するアーカイブの閲覧とZIPの展開。
- **編集:** 文字コードと改行コードを保持したテキスト編集、検索・置換、シンタックスハイライト、Markdownのライブプレビュー。
- **Git連携:** ファイルの変更状態と、HEADと編集内容の差分を表示。未保存の変更も比較できます。Gitの導入は任意です。
- **利用環境に合わせた設定:** 英語・日本語のUI、Standard/Nano/Vim/Customキーマップ、テーマの変更。WSLのファイル操作と読み取り専用のSFTP閲覧にも対応します。

対応形式や、ローカル・WSL・SFTPでの違いは[機能と制限事項](features.md)をご覧ください。

## インストール

対象環境は**Windows 11 x64**です。[GitHub Releases](https://github.com/cyan-cs/piero/releases)でプレビューパッケージの公開状況を確認してください。

- **ポータブルZIP:** 新しいフォルダーにパッケージ全体を展開し、ターミナルから`piero.exe`を起動します。`languages/`、`LICENSE`、`LICENSES/`は実行ファイルと一緒に置いてください。
- **インストーラー（公開されている場合）:** 画面の案内に従います。管理者権限を使わず、自分のアカウントにインストールします。ユーザーPATHへの追加は任意です。

配布パッケージはCランタイムを静的にリンクするため、Visual C++ランタイムを別途インストールする必要はありません。
パッケージがない場合は[ソースからのビルド](development.md#ソースからのビルド)を参照してください。
初回の設定は[導入ガイド](getting-started.md)、配布に向けた検証上の制限は[パッケージ作成](packaging.md)に記載しています。

## 基本的な使い方

`piero.exe`を起動するか、`piero.exe C:\Work`のようにフォルダーを指定します。
初回起動時に言語、キーボードプロファイル、テーマを選びます。

**Standard**プロファイルの基本操作です。

| キー | 操作 |
| --- | --- |
| 矢印キー、`h` / `l` | ファイルやフォルダー間の移動 |
| Space | 項目を選択 |
| `y`、移動先で`p` | 選択した項目、またはカーソル下の項目をコピー |
| `e` | 内蔵エディターを開く |
| `?` | 現在のキー操作一覧 |
| `,` | 設定を開く |
| `q` | ファイルマネージャーを終了 |

ほかのプロファイルではキーが異なります。詳しくは[キー操作](keybindings.md)をご覧ください。

## 動作環境と制限事項

- Windows 10での動作は未検証です。インストーラーにはWindows 11（build 22000以降）が必要です。
- 画像・PDFのプレビューにはAppContainerの隔離機能が必要です。画像形式やSixel表示は、導入済みのコーデックや端末の対応状況に依存します。
- Git連携にはWindowsの`git.exe`、または対象のWSLディストリビューション内の`git`が必要です。通常のファイル管理や編集にGitは不要です。
- 上書きは元に戻せません。ローカルの削除はごみ箱を使い、WSLの削除は完全に削除します。Undoの対象は一部の操作に限られ、終了すると失われます。
- セッションの保存は既定で無効です。エディターの下書きは別の機能で、除外条件付きで既定で有効ですが、最後の編集を必ず復元できるわけではありません。

重要なデータを扱う前に[安全性と制限事項](safety.md)を確認してください。

# Security policy

[English policy](docs/en/security.md) | [日本語の方針](docs/ja/security.md)

No stable version is currently supported.

To report a vulnerability privately, open the repository's **Security** tab and
choose **Report a vulnerability** (GitHub Private Vulnerability Reporting). If that
option is unavailable, open a public issue that only asks for a private channel, with no
details of the problem. Do not put sensitive details, credentials or private
documents in public issues.

Known limitations and data-preservation rules are in the
[safety guide](docs/en/safety.md) / [安全性ガイド](docs/ja/safety.md).

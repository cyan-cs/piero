Unicode character data used by piero
===================================

src/text/wf_width_ambiguous.h contains ranges derived from Unicode 15.0.0
East_Asian_Width=A through Python's unicodedata module. The range format is
generated by tools/make_ambiguous_width.py, not copied Python implementation
code. src/text/wf_width.c contains selected/combined Unicode width ranges.
These are modified representations of Unicode data, not original data files.

Data source: https://www.unicode.org/Public/15.0.0/ucd/EastAsianWidth.txt
